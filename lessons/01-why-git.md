# Lesson 1: Why Git?

## 🎯 Why do you want to learn Git?

Welcome to the Git Going self-paced Git course! You're about to learn a tool and workflow that will change your life.

Git is the most widely used version control system in the world, and for good
reason. Whether you're a solo developer or part of a large team, Git helps you:

- **Track changes**: Every modification you make is recorded. You can see what
  changed, when it changed, and who changed it.
- **Undo mistakes**: Made a mistake? Git lets you roll back to any previous
  version of your work.
- **Work on multiple features**: Create separate "branches" to work on different
  features without affecting your main codebase.
- **Collaborate with others**: Multiple people can work on the same project
  simultaneously without overwriting each other's work.
- **Review before merging**: Pull requests let teammates review changes before
  they're merged, catching bugs and sharing knowledge.
- **Back up your code**: With remote repositories (like GitHub), your code is
  safely stored in the cloud.
- **Work from anywhere**: Git is distributed, so you and your team can work from
  any location and sync changes when ready.
- **Keep documentation with your files**: README files, notes, and project
  documentation live right alongside your work - no more hunting through emails
  or wikis.
- **Automate workflows**: Git integrates with CI/CD pipelines, hooks, and other
  automation tools to test, build, and deploy your work.
- **Organize projects**: Structure your work through repositories and
  directories with clear history of how everything evolved.

Even if you're not a programmer, Git is useful for:

- Writers tracking document revisions
- Researchers managing data and analysis scripts
- Designers versioning configuration files
- Anyone who has ever named a file `final_v2_FINAL_really_final.doc`
