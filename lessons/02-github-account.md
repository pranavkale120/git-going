# Lesson 2: Setting Up a GitHub Account

## 🚀 Why GitHub is a good place to start

GitHub is the world's largest platform for hosting Git repositories. While Git
itself is a tool that runs on your computer, GitHub provides:

- **Free remote storage** for your repositories
- **A web interface** to view your code and history
- **Collaboration features** like pull requests and issues
- **A portfolio** to showcase your work to employers
- **Access to millions** of open source projects

Think of Git as the engine and GitHub as the highway system that connects
everyone. Note, Gitea and Gitlab are similar to GitHub, and everything you learn here is applicable.

## 📝 Creating an account

1. Go to [github.com](https://github.com)
2. Click "Sign up" in the top right corner
3. Enter your email address
4. Create a password (use a strong, unique password)
5. Choose a username (this will be visible to others, so choose wisely)
6. Complete the verification puzzle
7. Check your email and verify your account

## 📦 Create a repo named "git-going"

A "repo" (repository) is where Git stores all your project files and their
history. Let's create your first one:

1. Log into GitHub
2. Click the **+** icon in the top right corner
3. Select **New repository**
4. For "Repository name", enter: `git-going`
5. Add a description: "My Git learning journey"
6. Select **Public** (of you want the world to see it), or **Private** is fine.
7. Check **Add a README file**
8. Click **Create repository**

## 🤝 Add me as a collaborator on the repo

Adding me as a collaborator allows me to view your repository and provide
feedback directly through GitHub issues and pull requests.

1. Go to your new `git-going` repository on GitHub
2. Click **Settings** (gear icon) in the top menu bar
3. In the left sidebar, click **Collaborators**
4. You may be asked to confirm your password
5. Click the **Add people** button
6. Search for `bec-gitgoing` or enter the email `gitgoing@bec-systems.com`
7. Select the user and click **Add bec-gitgoing to this repository**

I'll receive an invitation and once I accept, I can see your work and leave
comments.

**Important:** Once your GitHub account is set up, all future lessons will be
delivered through GitHub issues on your repository instead of email. This gives
you practice using GitHub's collaboration features as part of the learning
process.

Congratulations! You've created your first Git repository.
